# Era — countdown timer

A precise countdown timer for important events: holidays, seasons, and custom dates.

## Features

- **Precise countdown:** Days, hours, minutes, and seconds until an event.
- **Dynamic themes:** The site's color scheme changes based on the nearest or most recent event.
- **Timezone support:** All timezones supported. Events begin at 00:00 local time for the selected zone.
- **Dark theme:** Automatic system dark mode support with a manual toggle.
- **Custom timers:** Create your own timers and share them via direct link.
- **Dynamic dates:** Automatic calculation of Orthodox and Catholic Easter, Maslenitsa, and Islamic holidays (Ramadan, Eid al-Fitr, Eid al-Adha).

## Technology

Built with vanilla web technologies, no frameworks or bundlers:

- HTML5
- CSS3 (with CSS custom properties)
- Modern JavaScript (ES6+ modules)
